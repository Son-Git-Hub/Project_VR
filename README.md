# 폐건물 탈출 게임 계획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | Escape from reality |
| 장르 | 추리 / 어드벤처 / 생존 |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | First Person |
| 예상 플레이 시간 | 10~15분 |

### 한 줄 소개
> 폐쇄된 건물에서 여러 위협을 피해 키를 획득하여 제한 시간 안에 탈출하는 방탈출 게임
---

## 2. 게임 컨셉

플레이어는 

맵 내부에서 여러 위협들을 피해 여러 아이템들을 획득하고, 아이템들 중 플레이어는 탈출에 필요한 열쇠(Key)를 찾아야 한다.

최종적으로 키를 이용해 출구를 개방하고 폐건물을 탈출하면 게임을 클리어한다.

### 핵심 키워드

- 탐험 : 폐건물 탐색
- 파밍 : 탈출에 필요한 아이템 획득
- 탈출 : 탈출구 개방 및 게임 클리어

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 폐쇄된 건물 내부를 탐색한다.
2. 맵 곳곳에 배치된 아이템들을 획득한다.
3. 배치된 아이템들 중 키를 찾는다.
4. 키를 사용하여 문을 연다.
5. 제한 시간 안에 키를 이용해 탈출하면 게임 클리어

---

## 4. 게임 주요 흐름

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
탈출에 도움이 되는 아이템 획득
  ↓
다음 구역 이동
  ↓
키(Key) 획득
  ↓
탈출
```

플레이어는 게임이 종료될 때까지 **탐색 → 전투 → 아이템 획득 → 이동**의 과정을 반복한다.

---

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Left Click | 총 발사 | --> 필요시 추가
| Right Click | 조준 | --> 필요시 추가
| Space | 점프 |
| Shift | 달리기 |
| E | 아이템 획득 / 문 상호작용 |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 1인칭 FPS 방식으로 맵 내부를 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 점프
- 달리기
- 상호작용
